# HorizonQuest — PRD & Build Log

## Original Problem Statement
Gamified education platform. Stack: React + FastAPI + MongoDB. Auth: Google sign-in (Explorers/students + Guides/teachers). AI: Claude (copilot hint assistant). Curriculum: 4 Territories, 33 quests, standards mapped DOK 2–4, auto-graded trials (80% mastery). Gamification: Journey map, Horizon Points, Compass Marks, Explorer Rankings leaderboard with Fleets. Guide Console: standards-mastery tracking, review queue, join codes, leaderboard controls.

## User Choices (confirmed)
- Auth: Emergent-managed Google Auth
- AI: Emergent Universal LLM key + Claude Sonnet 4.6 (claude-sonnet-4-6)
- v1 curriculum content generated by builder (content packs were not attached)
- Scope: full end-to-end slice

## Architecture
- Backend: FastAPI (`/app/backend/server.py`), all routes prefixed `/api`. MongoDB via motor. Session-token auth (httpOnly cookie + Bearer fallback). Curriculum in `/app/backend/curriculum.py` (public view + answer keys + grader).
- Frontend: React (CRACO), Tailwind + shadcn/ui, framer-based CSS animations, recharts. AuthContext + role-gated routes. AI copilot via fetch streaming.
- Theme: "Luxury Dark & Cartography" (Cormorant Garamond / Outfit / JetBrains Mono; gold + teal on deep ocean navy).

## User Personas
- Explorer (student): joins expeditions, sails the Journey Map, completes Trials, earns points/marks, competes on the leaderboard.
- Guide (teacher): creates Expeditions + join codes, reviews reflections, tracks standards mastery, controls leaderboard visibility.

## Core Requirements (static)
- Google sign-in with role selection (Explorer/Guide)
- Guide: create Expedition + join code; review queue; standards mastery; leaderboard controls
- Explorer: join via code (auto Fleet assignment); Journey Map (4 territories, 33 quests); Trials with auto-grading (80% mastery)
- Gamification: Horizon Points, Compass Marks, Explorer Rankings + Fleet standings
- AI Copilot (Claude Sonnet 4.6) giving hints, never answers (streaming)

## Implemented (2026-06) — Iteration 8: Assessments (checkpoint tests + comprehensive final)
- ✅ **Checkpoint tests**: a 20-question MC test at the end of each block of Skill Studio lessons — 3 per track (12 total). Each draws 20 from a 24-question curated pool with **answer options shuffled per student** (anti-cheat). **1 retake** (max 2 attempts), **70% to pass**, passing awards **+150 Horizon Points** (first pass only). Unlocks only after the covered missions are passed (score ≥60).
- ✅ **Comprehensive Final**: one exam for all expeditions — 25 questions drawn from a 30-question pool spanning all 4 tracks, 70% pass, **no retakes**, graded but ungated.
- ✅ **Anti-cheat**: banks server-only with correct answer as index 0; engine draws a random subset + shuffles options per attempt; per-attempt answer key stored server-side. Re-starting reuses the unsubmitted attempt (no question-mining).
- ✅ **Visibility**: students see best scores on the Journey Map ("My Test Scores"); Guides get a **Test Scores** gradebook tab (track-distinct columns, CSV export). Guides can take any test in teaching-preview (0 points, nothing saved).
- ✅ Backend: bank_docs/sheets/slides/email.py + bank_final.py + assessments.py engine; endpoints /assessments/track/{track}, /assessments/final/meta, POST /assessments/{id}/start & /attempts/{id}/submit, /me/assessments, /assessments/reports.
- ✅ Tested 100% (iteration_21): backend 13/13 new pytest; frontend all flows (checkpoint cards, quiz runner+retake, final, dashboard panel, gradebook+CSV). ⚠️ Requires **redeploy** for production.
